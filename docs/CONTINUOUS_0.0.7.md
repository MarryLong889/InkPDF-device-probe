## 实现与兼容

- PDF 在一个纵向容器中连续排列，手指可以跨页滑动。PDF 只读取、解析一次；当前页及相邻页渲染画布，远页保留布局占位。启动时先读取各页尺寸，支持混合页面大小，不让占位高度改变造成跳页。
- 页面状态、保存计时器和异步保存任务独立。落笔按实际画布绑定页面；保存失败的离屏笔迹保留在内存，状态行提示其他页未保存。保存 / 重试会尝试所有已加载页，单页失败不阻止其他页保存。
- 已保存的远页释放笔迹缓存和撤销历史，返回时重新验证快照链。当前及相邻页最多 20 步撤销；翻到较远页、关闭或重启会清空相应历史，已保存结果保留。快速跳页加载期间可能短暂多留一页画布。
- 原有 `pdf-内容SHA256-p页码` 关联、独立快照、probeFormat=1 沿用。原 PDF 不改写、不上传；同内容副本仍共享笔迹，改名可重新选择恢复关联。
- 钢笔画完后不抬笔，末端在约 4 CSS 像素内停留 1 秒，尝试拟合直线、轴对齐矩形/方框、圆。移动超过容差取消预览并重新计时；抬笔确认，未满足几何条件保留手绘。荧光笔、橡皮和鼠标不触发。
- 拟合结果仍保存为普通点列，使用整笔平均压力。撤销一次恢复原手绘，再撤销一次删除；重做反向恢复。取消输入、切换工具或离开页面不提交拟合预览。识别阈值尚需 Pencil 实机校准，斜方框和椭圆暂不拟合。
- 主工具栏保持单行：打开、页码、钢笔/橡皮切换、荧光笔、颜色、粗细、撤销/重做。窄窗口可横向滚动工具栏；缩放、压感、保存读回、诊断等放入默认折叠的“更多”。页面切换保留工具与缩放。

## iPad 更新与复测（发布后）

1. 先在旧版本保存，备份 vault 的 `InkPDF-Probe` 文件夹。BRAT 更新插件，重新启用或重启 Obsidian，确认版本 0.0.7；保持 Scribble 关闭。若 BRAT 尚未列出 0.0.7，请稍后重新检查更新。
2. 打开原来的多页 PDF，先检查 0.0.6 笔迹位置和荧光笔样式。关闭“更多”，确认常用工具只有一行，页面空间明显增加。
3. 不点上下页，单指持续向上滑，跨过两页交界；再反向滑回。分别在第 1、2、5 页写 A、B、C，写完立即滚动；页码应随视野更新，笔迹不能串页。
4. 快速滑到较远页后返回，等“页面加载中”消失再落笔。查看原有笔迹；在页界附近给两页各画一笔，确认归属正确。在“更多”选择 150% 或 200%，重复滚动和写字，确认坐标正确。
5. 钢笔画较长直线，末端保持接触约 1 秒，观察变直后抬笔。再画闭合方框和圆，重复停留；每种至少 5 次。少于 1 秒抬笔应保持手绘；拟合后继续移动应恢复手绘。正常写中文不应频繁误拟合。
6. 拟合后点撤销：应先回到原手绘，再撤销才删除；两次重做恢复拟合。切换荧光笔画线并停留，应保持荧光笔原行为。测试橡皮、撤销、重做不退化。
7. “更多 → 保存并重新读取”。第 1、2、5 页分别导出诊断、截图，记录页码和笔数。关闭重开，再正常退出并重启 App，回到相同三页逐页核对、导出诊断。历史计数可清零，笔迹与样式不可丢失。
8. 回传同页重启前后诊断、页界滚动和拟合的短录屏、工具栏截图；注明是否跳页/卡顿、拟合误触发率、停笔是否约 1 秒。不要为测试主动强杀仍显示未保存的 App。

## 本阶段边界

仍有每页 200 笔、100000 点、单 PDF 20 MiB 的探针上限；未验证数百页启动性能和 iPad 峰值内存。手指书写模式采用已有手动滚动，不承诺系统惯性或双指捏合。未做 OCR、套索、导出或 Pencil 笔体双击。发布附件仍限 main.js、manifest.json、styles.css；发布范围已获用户授权。
