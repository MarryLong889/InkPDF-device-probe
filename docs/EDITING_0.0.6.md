# 0.0.6：撤销重做、荧光笔与样式

2026-10-26。以 0.0.5 为基线，尚待 iPad 实机验收。当前页完整编辑历史与画笔样式在同一小阶段实现，未展开 OCR、套索和导出。

## 行为

- “撤销”“重做”取代旧的“恢复擦除”按钮。每次完成书写或一次整笔擦除算一步；撤销擦除恢复笔迹，重做再次擦除。恢复结果本身可重做/撤销。
- 最多保留 20 步，并按历史引用笔迹的点数限制内存预算（200000 点）。切页、关闭视图或重启清空历史；已保存的编辑结果保留。新书写或有效擦除会清空重做分支；单纯改颜色、粗细不会清空。
- 工具按钮及“切换钢笔 / 橡皮擦”命令继续使用；新增“荧光笔”按钮。点击荧光笔时默认黄色；随后可以更换颜色。工具按钮从荧光笔返回钢笔，再次点击切到橡皮。笔体双击仍暂缓。
- 五种颜色：蓝、黑、红、黄、绿。三档粗细：0.5×、1×、2×。样式只影响新笔迹，不修改旧笔迹。颜色/粗细属于当前视图设置，切页重置；每笔已保存的样式不重置。
- 钢笔保留压感与增益；荧光笔采用固定宽度（标准为 12 PDF 单位）和 30% 不透明度。不同荧光笔叠加会变深；同一条笔迹按完整路径绘制，避免逐段透明叠加接缝。
- 橡皮命中范围考虑实际笔画宽度，粗荧光笔也可从边缘擦除。仍是整笔擦除。
- 撤销/重做结果走现有自动保存、读回、失败重试及逐页隔离流程。原 PDF 只读，不上传内容。

## 数据兼容

Stroke 新增可选 kind（pen/highlighter）、color（六位十六进制颜色）、size（倍率）。读取时校验这些字段。缺失字段的旧笔迹按原蓝色钢笔、原宽度规则显示，旧版 p1/pN 数据不迁移、不覆盖。

本版继续使用 probeFormat=1 的可选字段扩展。旧插件虽能读快照，但不识别样式，可能把荧光笔显示成普通蓝线；创建新样式后不要用旧版本进行编辑。升级前备份 InkPDF-Probe。

## iPad 联合测试（发布后）

1. BRAT 更新到 0.0.6，重新启用插件；保持 Scribble 关闭。先检查 0.0.5 的旧页笔迹和位置正常。
2. 在测试页画三笔 A/B/C，撤销三次应回到原笔数；重做三次应恢复全部。擦除 B，再撤销/重做，核对位置和笔数。
3. 撤销最后一笔，再画新的一笔，确认重做不可用。连续操作超过 20 步时，最多保留最近 20 步是预期行为。
4. 分别用红色细钢笔、蓝色粗钢笔写字，再画黄/绿荧光线覆盖 PDF 文字。确认文字可辨、粗细可区分，改变设置不影响旧线。
5. 撤销再重做荧光线，确认颜色、粗细、透明度不变；擦除荧光线并撤销恢复。用同一笔来回描画检查接缝，另起一笔重叠时颜色变深属于预期。
6. 保存重读，缩放 100%/200%，切到第 2 页做不同样式标记，再切回来；各页笔迹与样式应保持，不串页。
7. 各页保存后导出诊断并截图，正常重启，再核对两页笔数、位置、颜色、粗细、透明度。历史计数清零是预期；编辑结果不应消失。

回传：两个测试页重启前后的 4 份诊断、包含荧光覆盖文字和不同粗细的截图，以及撤销/重做是否正确、有无新断笔或延迟。无需提供私人 PDF。

## 验证与限制

构建通过；16 项核心测试、17 组 Chromium 集成检查通过。包括样式非法值拒绝、旧笔迹兼容、撤销/重做顺序、新编辑清空重做、样式保存恢复、粗线擦除、荧光笔内部 alpha 约 30%、重开前后数据和绘制边界一致，及原有多页/保存失败回归。

浏览器逐像素比对未完全一致，重开前后存在像素差异；进一步验证的笔迹数据、画布尺寸、几何边界和荧光笔内部透明度一致，截图检查未见明显变化。不宣称像素级一致，iPad 需检查视觉效果。

荧光笔当前每帧重画当前整条路径，极长笔迹仍需设备性能测试。原有 200 笔/100000 点每页限制保留；撤销历史不跨页或跨重启。不含真实 iPad 新版验收、后台强杀或同步冲突实测。
