# 0.0.3 iPad 探针验收记录

日期：2026-10-26。设备沿用用户报告的 iPad Air 5 / Apple Pencil 2；日志确认 Obsidian API 1.14.5、PDF.js 5.3.34。依据两份诊断（1792979606354、1792979628808）、截图及用户明确反馈。原始诊断和截图未复制到仓库。

## 本轮结论

单页合成 PDF 探针的书写连续性、书写模式单指滚动、多步擦除恢复及正常重启保存通过本轮实机验收。0.0.3 可作为后续验证的基线；不据此认定完整 PDF 批注插件或 OCR 已可用。本轮仅记录结果，没有修改功能或发布新版本。

| 项目 | 证据与结论 |
| --- | --- |
| 单指滚动 | 用户确认正常；重启前 mode=write、188 次拖动处理、166 次实际滚动变化；重启后 37 次拖动处理、19 次实际变化，继续通过 |
| 触摸门槛 | 重启后仅一次触摸，最大接触尺寸 62.65px，成功滚动；这证实旧版 40px 尺寸门槛会拒绝本机这种有效触摸。不能追溯归因旧版全部 42 次拒绝 |
| 连续书写 | 用户确认不再出现断笔；最近 30 笔均 pointerup，取消、捕获丢失、捕获失败均为 0；本次最大采样间隔约 21ms |
| 多步恢复 | 用户确认连续恢复正常；截图和诊断显示重启前剩余 3 步。重启后为 0，符合会话内历史设计，不表示已恢复笔迹丢失 |

重启前 11 次触摸拒绝均记录为多指，活动触摸最终归零。blockedPen=0，不能据此认定本轮覆盖了笔接触时掌拒。101 次 penDown 包括橡皮输入，最终 83 笔还受擦除/恢复影响，二者差额不应解释为丢笔。

## 性能与边界

本轮最大增量绘制耗时 2ms；35 次保存最大耗时 268ms。上轮最大保存约 1132ms，但两轮快照历史规模不同（35 对 103 个 revision），本轮没有改动保存算法，不能将差值视为已修复保存性能。累计快照与完整链检查的增长成本仍待长期测试。

manualResults 的 NOT RUN 是程序不能自动判断人工项目的占位值；本记录用用户反馈补充，不修改原始日志。

Scribble 状态无法从诊断读取；此前关闭后改善，本轮未重新明确报告开关状态，不将结果外推到开启 Scribble。仍建议沿用关闭基线。

尚未验证：大文件/多页/旋转裁切真实 PDF、后台强杀、低存储、跨设备同步冲突、长期连续书写、OCR/ORT/SIMD；恢复历史不跨重启。
