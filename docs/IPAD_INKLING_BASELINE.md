# iPad：完整 Inkling 基线验收

适用：InkPDF (Inkling base) 0.0.10，基于 Inkling 1.0.1。Release 地址：https://github.com/MarryLong889/InkPDF-device-probe/releases/tag/0.0.10 。

## 安装

在 BRAT 对现有 `MarryLong889/InkPDF-device-probe` 执行更新，完整重启 Obsidian，在插件列表核对版本 0.0.10 和显示名 InkPDF (Inkling base)。最低 Obsidian 1.13.0。

也可手动把根目录的 main.js、manifest.json、styles.css 放入测试 vault 的 `.obsidian/plugins/inkpdf-device-probe/`，停用插件后覆盖，重启并启用。三个文件须同时更新。本地可安装文件夹为 `.test/install-0.0.10/`。

不要同时启用原版 Inkling。保留旧 InkPDF-Probe 数据；本版不导入旧侧车笔迹，也没有旧的“导出诊断”按钮。

**此次会写回 PDF。** 用两份测试副本，避免测试失误修改唯一原件；本轮不要在其他设备同时编辑同一 PDF。系统 Scribble 保持关闭，便于与此前测试比较。

## 进入批注

正常打开一个 vault 中的 PDF，在 PDF 视图点击铅笔动作“Annotate with Inkling”，或在命令面板运行本插件的 **Annotate this PDF**。它只在当前为 Obsidian 原生 PDF 视图时可用。不再通过旧设备探针入口打开。

## 分组测试

1. **打开与翻页**：测试 3 页以上 PDF，连续滚动、页码跳转、双指缩放，观察空白页、错位、卡顿；记录文件大小和页数。
2. **书写与导航**：每页写 A/B/C 标记和连续长线；测试轻重压、快速短笔画、掌触、抬笔后手指滚动。确认工具栏没有遮住主要书写区。
3. **工具**：钢笔、荧光笔、橡皮擦各做几次操作；测试撤销／重做。套索选中两条笔迹移动、缩放，确认未选中内容不受影响。
4. **图形**：设置 Pen → Shape recognition 为 Hold to snap。分别一笔画直线、方框、圆／椭圆，在末端保持接触至少 1 秒再抬笔，检查最终结果。上游约 500 ms 判定、提交时拟合，不要求出现旧探针的实时状态行。另测显式直线、矩形、椭圆工具。
5. **PDF 写回**：设置 Save frequency 为 Frequent，停止操作后等待至少 15 秒，正常退出批注回到普通 PDF 阅读器。确认笔迹在普通阅读器仍可见；重新进入批注检查。若出现保存错误提示，记录原文，不把“屏幕有笔迹”当作保存成功。
6. **重启与跨页**：确认退出批注后再重启 App，重开各页比对 A/B/C 标记、颜色和位置，检查无丢失、无串页。可用另一 PDF 阅读器打开测试副本，确认标准批注可见。
7. **原有扩展功能（可选）**：测试文本高亮提取到 Markdown、便笺和 Markdown ink block，记录哪些确实有用。文本提取不等于识别手写字。

## 回传

- 插件版本、Obsidian 精确版本、PDF 页数／大小。
- 每组通过／失败；失败的最短操作顺序、截图或录屏、错误提示原文。
- 图形各自成功次数／总次数，以及使用停笔识别还是显式工具。
- 关闭重开、App 重启、普通 PDF 阅读器中笔迹是否一致。
- 哪些现有功能已满足、哪些必须改；手写转印刷体已登记为确定缺项。

本版没有自写诊断 JSON 导出，请勿寻找旧探针按钮。无需发送私人 PDF；涉及具体文档时可另做不含隐私的最小测试 PDF。
