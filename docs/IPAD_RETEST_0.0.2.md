# iPad 测试分析与 0.0.2 复测

日期：2026-10-26。0.0.2 是本地待发布修复版，尚未通过 iPad 实机复测。

## 0.0.1 的实测结论

依据用户提供的两份 diagnostic JSON（时间戳 1792976950684、1792976991315）、截图及反馈。原始诊断和截图不纳入仓库。

设备：iPad Air 5 / Apple Pencil 2；用户报告 iPadOS 27.0.0.1；日志记录 Obsidian API 1.14.5、PDF.js 5.3.34、DPR 2。BRAT 精确版本待确认。

| --- | --- | --- |

## 修复及取舍

- 绘制拆成已完成笔迹层与当前笔迹层，按动画帧增量绘制，避免每个采样点重画全部历史。
- document 级 move/up 继续接收捕获丢失后的事件；补齐抬笔终点；只有宽度变化才重新适配页面，避免高度变化直接截断当前笔。
- 新笔迹默认压感增益 2.5×，可选 1× / 4×；显示实际压力。旧笔迹不修改，仍采用旧宽度规则。增益仅改变视觉映射，不制造不存在的压力信息。
- 整笔橡皮删除命中的整条笔迹，一次拖动算一次操作；“恢复上次擦除”只恢复最近一次擦除，画新笔后失效，重启后不保留撤销历史。
- 书写模式抬笔 180 ms 后可单指拖动页面；笔接触期间阻止手指导航，多指或大接触面不启动拖动。暂不做惯性滚动、双指缩放或 Pencil 双击切换工具。
- touch-action:none 保留，单指导航由探针处理。不能简单改为 pan-y：原生手势可能接管笔输入；参考 [Pointer Events 规范](https://www.w3.org/TR/pointerevents3/)。实际 WKWebView 行为仍须复测。
- 抬笔后自动保存合并等待约 250 ms；保存按编辑版本判断，正确处理擦除后笔数减少、恢复后笔数相等、失败旧快照重试。不再以笔数代表编辑是否已保存。
- 保留不可变快照、完整链校验、读回验证和冲突停止写入；未采用跳过链检查的优化。累计快照仍随编辑增长，尚不适用于长期大量批注。
- 诊断新增捕获丢失、结束原因（最近 30 笔）、采样间隔、绘制与保存耗时、手指拖动计数；不包含笔迹坐标或 PDF 字节，不上传第三方。

## 更新与复测步骤

以下步骤在 0.0.2 正式发布后执行。当前已有 0.0.1 不会自动变成本地修复版。

1. 先等旧版显示“已保存并读回校验”，备份测试 vault 的 InkPDF-Probe 文件夹。BRAT 检查更新并更新 InkPDF，关闭并重新启用插件；确认诊断 probeVersion 为 0.0.2。
2. iPad 设置 → Apple Pencil → 关闭“随手写 / Scribble”。本轮以关闭为基线，无需为了复现问题重新开启。
3. 打开“继续设备探针”，确认旧 43 笔仍在、位置正确。再使用“新建独立设备测试”做以下测试，避免影响旧样本。
4. 在书写模式画 20 条连续长线，每条约 3～5 秒，并写两行汉字。记录实际落笔次数与状态笔数，留意中段空缺、突然截断或接续直线。不要仅凭笔数一致判断无断笔。
5. 默认 2.5× 画轻、重压线；再对比 1× / 4×。截图保留压力读数与线宽，反馈是否能明显区分。用新画的线比较，旧线不随设置变化。
6. 抬笔后单指上下拖动，再在 200% 下左右拖动。预期页面移动且笔数不变。笔在书写时手掌贴屏，预期不误画、不带动页面。
7. 点击“工具：钢笔”切换整笔橡皮，擦一条孤立线，记录笔数减少；点击“恢复上次擦除”，确认恢复。再次擦除，等保存后点击“保存并重新读取”。密集线条落在擦除范围内可能同时删除多笔。
8. 100% / 150% / 200% 检查对齐，切换侧栏或横竖屏后再画线。改变页面宽度期间结束当前笔是本版预期行为。
9. 等待“已保存并读回校验”，导出第一份诊断。退出并重启 App，打开继续测试，核对笔数、擦除结果、线宽及位置，再导出第二份。

发回：两份 JSON、一张含压力读数和轻重线的截图、断笔是否改善（最好“20 条中有几条断”）、滚动是否正常、擦除/恢复与重启前后笔数、实际 Scribble 状态。若仍断笔，补充短屏幕录像和发生时是否滚动/切换侧栏。无需发送个人 PDF 或完整快照。

诊断 manualResults 仍为 NOT RUN，表示程序无法自动判断人工项目；以你的观察补充，不代表上述人工测试没做。

## 本地验证与剩余风险

TypeScript 构建通过；12 项核心测试通过；9 组 Chromium 集成检查通过，见 tests/evidence。包括保存失败重试、删除到零后恢复、擦除后重开、捕获丢失继续输入、纯高度变化不截断、笔接触阻止手指滚动和抬笔后滚动。浏览器截图已检查。

浏览器使用模拟 Obsidian 宿主和 PDF.js 6.4.299；设备使用宿主自带 PDF.js（旧日志为 5.3.34），因此桌面模拟通过不等于 iPad 验收。没有实测新版 WKWebView、真实 Pencil、后台强杀或 GitHub 同步冲突。

自动保存有等待窗口，App 在未保存时被系统强杀仍可能丢失最近修改；结束测试应等待保存状态。系统终止进程时无法保证异步保存完成。关闭 Scribble 是当前已验证有帮助的操作，新版不能宣称从程序层彻底解决系统截获。
