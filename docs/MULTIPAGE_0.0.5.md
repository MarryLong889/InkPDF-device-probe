# 0.0.5 多页试验与 Pencil 双击接口结论

日期：2026-10-26。以 0.0.4 为基线，尚未完成 iPad 实机验收。

## 本轮实现

- 上一页、下一页与当前页/总页数显示；到边界按钮禁用。仅渲染当前页，不做连续长页面或预加载。
- 切页前结束当前笔并等待快照保存及读回检查；保存失败则保留当前视图和内存笔迹，阻止翻页，用户可重试。等待切页保存时禁止开始新笔。
- 每页使用 `InkPDF-Probe/pdf-<源SHA256>-p<从1开始的页码>/snapshots/`。0.0.4 的 p1 路径与格式不变，无需迁移；各页独立 revision、笔数和版本链。
- 重启后“打开 / 继续设备探针”继续最后的文件与页码。关闭标签再继续同样恢复；通过文件选择框重新选择文件则从第 1 页开始。改名后需重新选择，从第 1 页开始，其他页可翻到后找回。
- 页面数量减少时，恢复页码限制到新的最后一页。文件字节变化仍使用新哈希目录，不与旧内容混用；旧笔迹保留。
- 每页沿用 200 笔、100000 点限制。擦除恢复历史是当前视图会话内历史，切页清空；已保存笔迹不会因此消失。切页重置缩放、滚动位置和工具为默认状态。
- 原文件只读，批注独立保存；没有 OCR、套索或导出。Release 仍只需三个核心文件。

为减少跨页状态风险，本版切页复用“保存后重开视图”路径，每次重新读取/哈希 PDF；仍限制 20 MiB。这比多页缓存慢，但不会同时维持多页可编辑状态。实际翻页延迟与内存开销待 iPad 验证，不宣称已优化大文档。

## Apple Pencil 笔体双击：尚未实现，原因与替代

用户所指是手指双击 Pencil 2 笔体，不是笔尖或手指双击屏幕。用户已同意暂缓笔体双击，先使用工具切换命令替代。

Apple 的 [UIPencilInteraction](https://developer.apple.com/documentation/uikit/uipencilinteraction) 通过原生 UIKit interaction/delegate 接收双击。检查本地 obsidian 1.14.4 类型声明，以及在线 [Obsidian 公共 API 声明](https://raw.githubusercontent.com/obsidianmd/obsidian-api/master/obsidian.d.ts)，未发现 Pencil 双击事件/桥接接口。没有证据可以把系统原生回调直接接入目前的 TypeScript 插件。

结论仅限“没有已验证可用的公共接口”；不假定未来宿主或未公开接口永远不能支持。没有添加虚构事件监听、屏幕 dblclick 替代、私有桥接调用或原生二进制。诊断明确记录 `pencilDoubleTap: UNAVAILABLE_NO_PUBLIC_HOST_API`。

已添加“切换钢笔 / 橡皮擦”命令，与工具按钮使用同一个实现。可通过 Obsidian 命令面板执行并观察按钮变化；这不是笔体双击。若未来 Obsidian 提供官方原生桥接，可将回调接到此切换方法，再验证系统偏好、防重复事件与实际 Pencil 2 双击。

## iPad 更新与验收

0.0.5 发布后通过 BRAT 更新，关闭再启用 InkPDF；确认诊断版本。备份 InkPDF-Probe，保持 Scribble 关闭，选一份已本地下载、未加密、20 MiB 以下且至少 3 页的测试 PDF。

1. 先打开之前 0.0.4 测过的文件，确认第 1 页原有 29 笔仍在（以实际旧测试为准）。不要为测试覆盖私人原件。
2. 在第 1 页写明显的 A 标记，记录笔数；抬笔后立即点下一页。在第 2 页写 B，在第 3 页写 C，各自记录笔数。不得出现其他页标记。
3. 依次 3→2→1→2→3，核对标记、笔数、相对于 PDF 内容的位置。各页测试滚动和 150%/200% 缩放；切页后缩放回到 100% 是本版行为。
4. 在第 2 页擦一笔并恢复，再翻到其他页，确认只影响第 2 页。切回来恢复历史为 0 是本版限制；已恢复且保存的笔迹仍应在。
5. 各页等待保存并导出一次诊断，命名注明“重启前-第N页”。诊断的 pdf.selectedPage 与 runId 末尾 pN 必须对应，笔数是当前页的笔数。
6. 停在第 2 页，等待保存后关闭标签，执行“打开 / 继续设备探针”，应回第 2 页。再正常重启 App、执行继续命令，确认仍在第 2 页；逐页核对标记和笔数，各导出一份“重启后-第N页”。
7. 将文件改名后重新选择，应从第 1 页打开；翻到第 2、3 页仍应找到对应笔迹。默认阅读器打开源 PDF 不应看到 InkPDF 笔迹。
8. 执行“切换钢笔 / 橡皮擦”命令，观察工具文字切换并实际擦除/恢复。笔体双击本版预期无响应，不列为通过项目。

回传 3 页重启前后的 6 份诊断（无需 PDF 或快照），以及逐页笔数、是否串页/丢笔、翻页等待时间、返回第 1 页旧笔迹情况。异常后先导出诊断，不删除快照。保存失败时留在原页重试，不强制退出。

## 本地验证

构建与 TypeScript 检查通过；15 项核心测试、16 组 Chromium 集成检查通过。新增：两页笔迹逐点隔离；抬笔即切页仍保存；重启恢复第 2 页及笔迹；注入写入失败阻止翻页、保留内存笔迹、重试后恢复；工具命令切换。保留原来的改名/替换隔离、文件只读、失败恢复和触控回归。

这是模拟宿主验证，尚未验证真实 Obsidian iPad、三页以上实机切换、大文档性能或后台强杀。Apple Pencil 原生双击未实现，不能计入验收完成。
