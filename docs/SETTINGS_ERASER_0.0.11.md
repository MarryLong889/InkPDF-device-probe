# 0.0.11：设置语言与整笔擦除

发行版本：0.0.11。Release：https://github.com/MarryLong889/InkPDF-device-probe/releases/tag/0.0.11

在 BRAT 更新 MarryLong889/InkPDF-device-probe，完全重启 Obsidian，在插件列表核对 0.0.11。Release 仅包含 main.js、manifest.json、styles.css。

## 使用方法

- 设置页顶部新增 **Language / 语言**：English、简体中文二选一。默认英语以兼容现有设置；选简体中文后立即刷新，重启后保留选择。
- 翻译范围：插件设置页分组、设置名称、说明、下拉选项、颜色字段名称和路径验证提示。工具栏、命令和运行时提示仍保留上游语言，未进行全插件汉化。用户自己填写的颜色分类值、路径和文件内容不自动翻译。
- **橡皮擦模式 / Eraser mode**：像素擦除（原有默认）或整笔擦除。修改后下一次擦除立即使用新模式，不需重开 PDF；在工具栏选择现有橡皮擦即可。
- 整笔擦除对 PDF 和 Markdown 手写块生效。触及笔迹线段即删除该条笔迹，可一次擦多条；沿用上游的一次手势一次撤销／重做与保存。形状和便笺继续保持原有整项删除行为。
- “整笔”指当前保存的一条笔迹。此前已被像素擦除切成多条的片段会分别作为笔迹；不会推断并重新合并原来的一整笔。

构建和类型检查通过；772 项测试通过，0 失败，2 项外部 PDF 样本库测试跳过。新增检查覆盖语言切换刷新、中文字段覆盖、保存偏好、保留用户分类值、非法设置拒绝、稀疏线段命中、整笔撤销重做、动态切换像素模式、真实 PDF 保存重开与跨页隔离。

## iPad 复测（发布或手动安装后）

1. 在插件设置中选择简体中文，检查分组、说明和选项；切回 English，再改中文，重启 App 检查选择仍保留。自定义一个颜色分类名，确认切换语言不会改写它。
2. 在测试 PDF 副本同页画两条长曲线，另页画一条。设置“整笔擦除”，工具栏点橡皮擦，碰第一条中部，应整条消失，第二条仍在。
3. 一次擦除手势划过两条，撤销应一起恢复，重做应一起删除。然后切为“像素擦除”，检查只擦除接触区域（采样点很少的笔迹可能整条被原像素算法删掉）。
4. 在缩放后的页面重复；正常退出批注、重新打开，再重启 App，检查擦除结果保留，另一页不受影响。PDF 仍直接写回，使用副本测试。
5. 若使用 Markdown 手写块，重复整笔擦除和撤销，关闭重开笔记检查。
